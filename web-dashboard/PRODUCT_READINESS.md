# 观基：产品化版本验收与运行

## 交付目标

提供可以每天使用的基金观察与记账工具：从找基金、关注、查看详情、记持仓，到查看收益与本地提醒，核心步骤连贯；公开数据有日期、失败态和恢复路径。公开访问入口为 https://tenltrist.github.io/fund-agent/ 。

本版本继续使用 GitHub 仓库、Actions 和 Pages。无付费接口、用户账户服务器、交易执行或个人数据收集。个人持仓金额不进入公共快照，旧 ChatGPT 站点不参与运行。

## 数据和功能边界

- 普通公开接口没有完整逐笔订单或投资者实名身份。“超大单/大单/中单/小单”是数据源订单分类，不能直接当成机构/散户真实账户；主力单列为超大单加大单。
- 公开接口存在限流和网络失败。部分个股资金曲线可能暂时缺失，或保留上次成功曲线。资金页保留来源时间；设置中的“公开数据发布健康”显示最近采集失败项。CI成功只说明程序与产物符合检查，不能证明所有上游接口都可用。
- 页面刷新频率与GitHub数据发布频率不同。交易时间判断基于常规工作日时段，节假日以来源行情日期为准；新抓取成功也不会把来源旧报价改成实时。
- 基金公开盘中估算覆盖有限；没有估算时显示确认净值。季报股票权重只能计算已披露且行情覆盖部分的贡献，不能还原当前完整基金仓位。
- 金额换算必须是同一确认日期、同一净值口径的持仓金额和持有收益，不应包含在途资金；金额舍入会影响推算份额，实际份额优先。
- 持仓使用移动平均成本，不替代基金销售平台的交易确认、FIFO赎回批次或实际费用单。这里只记账，不发起交易。
- 个人记录只在本浏览器。无跨设备云同步；关闭网页后的持续监控和个人云推送未提供。PWA外壳可离线打开，不会变成后台行情服务。
- 离线仅能读取该设备已成功缓存的公共文件；OCR大模型和外部数据桥不预缓存。恢复在线后，数据优先请求网络。

## 运行与维护

发布前运行 `npm test`、`npm run build` 和 `npm run validate`。推送main后检查Actions的Publish market dashboard工作流；成功后还要打开公开页面，检查新版入口、真实来源时间和核心链路。

源端失败时，先在设置页查看发布健康和各数据日期，再检查Actions采集日志。保留旧值时不能改写其`fetched_at`。不为通过验收而注入模拟行情，不把CI通过写成源端全量健康。

个人数据备份建议定期下载，并在清理浏览器数据、换设备或恢复文件前保留一份。备份恢复全量校验通过后才替换记录；存储不可用或空间不足时，账本写入失败会撤回内存变更并提示未保存。替换前的状态保存在同来源的`fund-observatory-v1-before-restore`。脚本启动异常时，独立恢复条仍提供原始记录导出与重新加载。

外壳更新使用内容哈希资源和网络优先导航；打开的旧窗口不会被强制刷新。无法显示新版本时先重载页面，避免清除个人浏览器记录。
