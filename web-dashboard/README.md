# 观基 · 基金观察与记账

直接访问 **[tenltrist.github.io/fund-agent](https://tenltrist.github.io/fund-agent/)**。源码、构建、定时数据更新和网页托管均在 GitHub；不依赖 Sites，不需要会员或 API Key。

## 日常使用

打开后先进入“今日看板”：查看自选基金、持仓参考资产、市场脉搏及待办。首次使用有三步引导，不需要注册。

1. 点击顶部搜索（支持 `⌘/Ctrl K`），按名称、代码或拼音查找基金；打开详情可关注、记持仓、加入对比。
2. 在“我的持仓”按账户记录平台已确认的份额和剩余成本；也可按**同日确认净值**将持仓金额与持有收益换算成份额，保存前必须核对日期与在途份额。
3. 持仓、交易记录和定投计划分别查看。新增交易日期晚于公开净值时显示等待，不用旧净值估算新份额。收益日历使用已记录交易和公开确认净值。
4. 提醒中心集中显示净值、涨跌、资金和定投事件。定期导出本地备份，恢复前自动保留原记录，可一键回退。

手机提供底部导航、更多菜单和逐基金持仓卡片。浏览器支持时可安装到桌面；首次成功访问后可离线打开外壳及已缓存的公共数据，离线数据始终保留原时间。外壳与数据缓存遵循 [MDN Service Worker 文档](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)及[Chrome 网络优先策略](https://developer.chrome.com/docs/workbox/caching-strategies-overview)。

## 监测与分析

- 大盘：5个主要A股指数、实际分钟走势、行业广度；Cboe VIX使用官方**日终**历史。
- 资金：超大单、大单、中单、小单四档独立曲线，主力单列合计；分钟/多日窗口、价格对照、区间变化、方向连续性、阈值提醒与CSV。
- 基金：默认13只、可维护最多60只自选、名称/代码/拼音搜索、涨跌/近月排序、全历史净值、公开经理/规模/配置、四基金同区间对比与风险指标。
- 持仓透视：按最近公开权重计算有同日行情的已披露部分贡献，展示覆盖比例；支持从重仓股下钻资金，不外推完整基金估值。
- 账本：多账户、份额与成本、加减仓及现金分红、交易撤销/恢复、收益日历与CSV、本地回撤阈值、定投待办。
- 导入：本机OCR、文本待核对草稿、批量交易、旧JSON快照；数据和识别图片不上传。
- 恢复：完整备份校验、导入前自动留底、损坏原文保留、独立启动错误恢复条。

## 数据怎样更新

GitHub Pages 仅托管静态文件。浏览器通过无同源权限的 sandbox iframe 读取腾讯公开报价/分时/日线、东方财富资金和基金档案，不把持仓交给来源脚本。直连失败时显示 GitHub 公共快照，保留原抓取时间和来源日期；超过15分钟标记数据较旧，不伪装成即时行情。

GitHub Actions 在工作日 UTC 01–03、05–06时每5分钟计划抓取，并在07:10、12:10、22:10补充收盘/基金/VIX。调度和部署可能延迟，**不是5分钟到点保证**；页面默认30秒刷新也不意味着快照每30秒更新。板块、基金估算与VIX使用公共快照，个股新增标的通过浏览器直连。节假日以行情来源日期为准。

抓取脚本只读取 `market-watchlist.json` 的公开代码，不读取个人持仓或峰值；只把 `dist/public` 上传 Pages。数据源限流、网络、接口变更可能导致缺失，页面会保留日期或显示不可用，不生成模拟行情。

净流入是订单规模与买卖方向的分类统计，不等于新增现金。行业可能存在上下级重叠，不能累加充当沪深总额。公开估算不是最终确认净值，披露重仓股也不是完整实时仓位。VIX是美股隐含波动率，使用官方日终文件，不是A股实时恐慌指数。

## 本地运行

需要 Node.js 24：

```bash
cd web-dashboard
npm ci
npm run snapshot       # 仅公共行情，可保留已有种子快照
npm run build
npm run validate
npm run preview        # http://127.0.0.1:8765/fund-agent/
```

`npm run dev` 可运行带 Node 数据接口的本地模式；`npm test` 检查数据映射、来源缺失处理、快照时间和峰值风控。GitHub 工作流在 `.github/workflows/pages.yml`，推送 main 或 Actions 手动触发都会发布。

## 个人数据和迁移

持仓、金额、峰值、自选和提醒记录只保存在当前网页来源的浏览器 localStorage，键为 `fund-observatory-v1`。不上传至 GitHub，不包含账户登录、云同步或交易功能；清理浏览器数据会丢失，建议导出备份。导入前记录保存在同来源的 `fund-observatory-v1-before-restore`，损坏的原文保存在 `fund-observatory-v1-recovery`；不会跨来源或跨设备自动同步。

旧网址与 GitHub Pages 是不同来源，浏览器不会自动共享数据。旧站点已按要求永久删除，已导出的备份可在 GitHub 网页的“数据与设置 → 恢复本地备份”导入。导入仅在浏览器处理；Python 的 `data/peak_state.json` 与网页峰值目前独立。

公开仓库的早期历史已经含过个人配置；本次移除了后续版本的跟踪，保留本机文件，没有改写 Git 历史。不要把真实持仓、浏览器备份或 `.venv` 上传仓库。

## 对照养基宝补齐的功能（2026-11-17）

新增“基金市场”“账户与记账”“收益日历”“识图与批量录入”四个页面。完整对照、来源和实际边界见 [FEATURE_PARITY.md](FEATURE_PARITY.md)。

账本按账户保存实际份额、剩余成本和已确认交易，采用移动平均成本分摊卖出；支持现金分红、已实现收益、逐笔撤销/恢复及每周/每月定投计划。收益日历扣除加仓现金流、加入减仓收入及现金分红；期初持仓按当日净值建立基线，不把期初历史浮盈当作当日收益。缺失净值或只有基线时留空，不能视为零收益或完整月报。现金分红/再投等变动需要按平台记录登记。

截图使用同站点托管的 Tesseract.js 引擎和中文/英文模型在本机识别，不向任何识图服务器上传。识别结果只生成待核对草稿，实际份额、剩余成本、成交净值和确认日期必须核对后保存。批量交易费用默认为0，有费用时使用逐笔记账。旧 JSON 快照可转成草稿，未提供的份额不自动反推。

基金市场支持类型与区间排行、CSV导出、最多4只基金的共同日期对比。风险指标基于来源日收益率复合计算，不用净值除息跳变冒充真实回撤；波动率采用252日年化。基金档案扩展经理、规模、资产配置与公开申购参考费率，并提供历史范围选择。展示的是公开披露数据，不代表当前完整仓位。

新增账本回撤、净值更新与定投到期通知均只在页面打开时工作。仓库不存个人账本；旧 ChatGPT 站点已永久删除，不再作为备份迁移入口。个人备份文件仍可在GitHub网页恢复。

## 四线资金终端与持仓穿透

资金页按超大单、大单、中单、小单画四条独立曲线，主力合计单独显示；支持沪深/沪市/深市/自选股、分钟窗口、多日累计、连续方向、同日价格对照、缩放、导出与阈值提醒。基金详情新增公开权重与股票行情的涨跌贡献，以及重仓股资金下钻。实现范围与计算公式见 [FLOW_METHODOLOGY.md](FLOW_METHODOLOGY.md)。

资金图可直接通过 [资金终端](https://tenltrist.github.io/fund-agent/#flows) 打开。所有页面均可使用URL片段定位，个人金额不进入URL或GitHub采集。
