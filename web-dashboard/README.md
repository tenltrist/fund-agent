# 观基 · GitHub Pages 市场监测台

直接访问 **[tenltrist.github.io/fund-agent](https://tenltrist.github.io/fund-agent/)**。源码、构建、定时数据更新和网页托管均在 GitHub；不依赖 Sites，不需要会员或 API Key。

## 功能

- 大盘：上证、深成、创业板、沪深300、科创50报价与实际分钟线。
- 资金：沪深合计及个股的主力、超大单、大单、中单、小单曲线，日内与近30交易日；行业资金排行、筛选和温度图。
- 基金：初始13只；代码/名称搜索、添加删除、清单导入；有效盘中估算优先，其余显示已公布净值；180条历史净值与披露重仓股。
- 个股：自选报价、分时、前复权日线和历史资金。
- 情绪：Cboe 官方 VIX **日终**历史；A股上涨板块占比。两者口径不同。
- 持仓与风控：本地 JSON 导入、真实快照日期、跨次保存的收益率峰值、价值回撤和提醒阈值。首次历史不足时显示待补数据。
- 设置：自动刷新、备份导出/恢复、浏览器桌面提醒。提醒只用于页面打开期间取得的当日直连报价；公共快照不触发实时提醒。

## 数据怎样更新

GitHub Pages 仅托管静态文件。浏览器通过无同源权限的 sandbox iframe 读取腾讯公开报价/分时/日线、东方财富资金和基金档案，不把持仓交给来源脚本。直连失败时显示 GitHub 公共快照，保留原抓取时间和来源日期；超过15分钟标记数据较旧，不伪装成即时行情。

GitHub Actions 在工作日 UTC 01–03、05–06时每5分钟计划抓取，并在07:10、12:10、22:10补充收盘/基金/VIX。调度和部署可能延迟，**不是5分钟到点保证**；页面默认30秒刷新也不意味着快照每30秒更新。板块、基金估算与VIX使用公共快照，个股新增标的通过浏览器直连。节假日以行情来源日期为准。

抓取脚本只读取 `market-watchlist.json` 的公开代码，不读取个人持仓或峰值；只把 `dist/public` 上传 Pages。数据源限流、网络、接口变更可能导致缺失，页面会保留日期或显示不可用，不生成模拟行情。

净流入是订单规模与买卖方向的分类统计，不等于新增现金。行业可能存在上下级重叠，不能累加充当沪深总额。公开估算不是最终确认净值，披露重仓股也不是完整实时仓位。VIX是美股隐含波动率，使用官方日终文件，不是A股实时恐慌指数。

## 本地运行

需要 Node.js 24：

```bash
cd web-dashboard
npm ci
npm run snapshot       # 仅公共行情，可保留已有种子快照
npm run build
npm run validate
npm run preview        # http://127.0.0.1:8765/fund-agent/
```

`npm run dev` 可运行带 Node 数据接口的本地模式；`npm test` 检查数据映射、来源缺失处理、快照时间和峰值风控。GitHub 工作流在 `.github/workflows/pages.yml`，推送 main 或 Actions 手动触发都会发布。

## 个人数据和迁移

持仓、金额、峰值、自选和提醒记录只保存在当前网页来源的浏览器 localStorage，键为 `fund-observatory-v1`。不上传至 GitHub，不包含账户登录、云同步或交易功能；清理浏览器数据会丢失，建议导出备份。

旧网址与 GitHub Pages 是不同来源，浏览器不会自动共享数据。在旧页面导出本地备份，再在 GitHub 网页的“数据与设置 → 恢复本地备份”导入。导入仅在浏览器处理；Python 的 `data/peak_state.json` 与网页峰值目前独立。

公开仓库的早期历史已经含过个人配置；本次移除了后续版本的跟踪，保留本机文件，没有改写 Git 历史。不要把真实持仓、浏览器备份或 `.venv` 上传仓库。
