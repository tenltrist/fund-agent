# 与养基宝公开功能的对照

核对日期：2026-11-17。依据仅为[开发者官网](https://www.yangjibao.com/)、[关于我们](https://www.yangjibao.com/about.html)、[官方FAQ](https://www.yangjibao.com/question.html)及[开发者App Store介绍](https://apps.apple.com/us/app/id1597754877)。未访问付费账号，也不把其他同名网站当作官方产品。公开介绍不是完整的会员功能清单。

| 功能 | 本次处理后 | 数据与实际边界 |
| --- | --- | --- |
| 多平台、多账户持仓汇总 | 已新增“账户与记账”，同基金可跨账户分别记账和筛选 | 份额、成本由本人录入；本地保存，不登录支付宝/券商读取私有账户 |
| 手工录入持仓、加减仓、现金分红 | 已新增基线、交易记录、移动平均成本、已实现与持有收益，支持可恢复的撤销 | 按平台已确认日期/净值记录，不下单。分红再投按已确认新增份额记录加仓；未记分红不能当作完整账单 |
| OCR截图录入 | 已新增本机中文/英文OCR、文字粘贴、旧快照转草稿 | 识别代码/名称；份额和成本/成交净值必须核对，勾选后保存；不能保证与养基宝的专有识图算法相同 |
| 交易截图批量加减仓 | 草稿支持期初/加仓/减仓/现金分红四种方式 | 仅批量导入核对后的记录，批量费用默认为0；非零费用逐笔登记 |
| 持有盈亏分析 | 已新增剩余成本、最新可用净值资产、持有盈亏、已实现收益和当日可计算浮动 | 不同净值日期逐行标注；当日浮动显示覆盖，排除当日发生交易的持仓；不会冒充全组合实时收益 |
| 收益日历、周报/月报 | 已新增净值日历、日收益图、当周/月已知收益和CSV | 以账本基线之后的确认净值及现金流计算，基线与缺失日留空；本地生成，不自动发邮件 |
| 净值/涨跌提醒 | 原涨跌提醒保留，新增确认净值更新通知、账本回撤与定投到期提醒 | 仅页面打开期间；桌面通知需浏览器授权，首次净值读取只建立基线，不把旧净值当作新通知 |
| 基金实时估值 | 保留公开来源有效估算及确认净值回退 | 当前默认13只有2只取得有效盘中估算，其余是确认净值；不根据不完整持仓伪造其余基金实时估值 |
| 持有峰值与回撤 | 原快照风控保留，新增每笔账户持仓的峰值、阈值 | 成本/资本交易变化重新建基线；无历史时待补，不倒推出不存在的过去高点 |
| 定投辅助 | 已新增每周/每月本地计划、到期提示、暂停和顺延 | 不扣款，不自动下单，顺延不代表已成交 |
| 基金排行和筛选 | 已新增约2万只公开净值排行，按类型/名称和日/周/月/季/半年/年/今年来筛选 | 天天基金公开数据，非平台基民真实申赎榜；不同基金净值日可能不同 |
| 基金对比和档案 | 已新增共同区间收益曲线、回撤、年化波动率、经理/规模/资产配置/公开申购参考 | 历史使用公开档案可提供的范围；披露数据有独立日期，费用以实际销售平台为准 |
| 备份与导出 | 全量本地备份恢复纳入新账本、计划、峰值；新增排行/交易/收益CSV | 个人数据不提交到GitHub；自动跨设备云同步未接入 |
| 大盘、资金、个股和情绪 | 已有真实报价/分时、沪深/个股资金、行业热图、VIX与A股广度 | 公开接口可能延迟或失败；VIX是美股日终，板块资金不是基金申购资金 |

无法由公开行情还原：养基宝用户加减仓榜、用户实盘/社区数据、其他平台私有持仓/交易及账号同步、专有估值算法、真实交易。关闭浏览器后的个人推送需要额外的服务端与个人订阅信息，本项目不把个人持仓放到公开Actions里实现它。

旧 ChatGPT 站点已按用户再次确认永久删除；GitHub Pages 是唯一在线应用入口。

## 用户纠正后的监测重点

本次不把基础账本当作高级盘中能力的替代，资金监测改为四档独立曲线与单列主力合计，并加入分钟异动、多日累计/连续方向、价格对照和资金提醒；基金详情加入公开持仓权重的盘中贡献及个股资金下钻。具体计算及数据依据见 [FLOW_METHODOLOGY.md](FLOW_METHODOLOGY.md)。养基宝各项功能当前是否收费未获完整核实，不将这些实现冒称为已逐项验证的会员权益清单。
